## 全项接入实施（2026-11-06）

本轮覆盖 P0–P2，复用已有水晶治疗、原生保护和发射快照。只维护 NeoForge 26.1.2.126；不扩展第三方组合、助攻计分、显示界面或展示网络。

### 行为与执行顺序

NeoForge 的实际顺序是 Incoming 事件（框架计算、取消和应用前计划）→物品格挡→无敌帧拒绝/差额→actuallyHurt 原生减伤与 Pre→自定义盾→原版吸收→生命写入与受管保护→原生死亡保护/死亡→Post 结算。不能把 Incoming 计算描述为发生在格挡之后。

- `successfulHit()` 要求完整、未取消的 APPLIED 结算，并至少消耗生命、自定义盾或原版吸收。零资源命中不发布 Hit，原生 hurt 返回值同步采用该判断。完全消耗原版吸收不再误判 ZERO_AFTER_PRE。
- 两类全盾吸收保留成功命中和恢复延迟；吸血只消费主伤害的确认生命损失。现有 Reflection 按生命损失比例反伤，保留原资格；原版荆棘等成功命中后处理可响应全盾命中。
- hurt 内攻击击退与受击 Effect、玩家/生物刺击在伤害拒绝后的额外击退、下马和武器处理，受实际命中结果约束。不造成伤害的独立刺击位移保留原生语义。正常攻击、横扫由 hurt 返回值控制附魔后处理。
- 横扫新增 `SWEEP` 请求类型，仍可闪避，默认禁止 proc，因此不享受主伤害吸血。各目标独立结算，复用攻击动作及冻结攻击者输入；目标防御按本次请求捕获。
- 原生保护记录物品消耗和设血的独立写入，普通致死伤害也合并保护日志。设为 1 不增加治疗或伤害生命损失。受管一次性保护先于图腾，消耗后不重复执行。
- 龙部位保留原版阶段判断和非头部缩放，返回实际父类受伤结果。未进入结算或被取消的部位攻击不再返回成功。PartHit 区分部位、主体与接受结果；转发仅结算一次。
- 箭、三叉戟、烟花沿用发射时射手输入与装备，换装和射手移除后仍使用原快照。无来源不猜测宠物主人装备。快照仍是投射物运行期数据，本轮不增加卸载重启恢复协议。
- Effect 观察采用活动效果前后差异，区分新增、刷新、升级、变化和移除，记录可确认调用来源。普通倒计时不发布刷新；嵌套调用只发布一组差异，不安装第二份属性、不另起计时器。死亡清理框架会话；原生尚未移除的效果不伪报为已移除。
- Death 增加直接实体和可用操作身份；逻辑攻击者优先取 DamageSource，缺失时可取已捕获投射物射手身份。原生统计、仇恨和宠物主人记忆保持原版执行；不按最终血量推断死亡、不新增助攻计分。

### API 与验证入口

`CombatMoment.Hit` 增加自定义盾消耗和动作身份，只发布成功命中；`Death` 增加直接实体和操作身份；`Effect` 从 present 布尔值改为前后状态、变化类型及可选来源。新增 `Protection`、`PartHit`；请求类型新增 `SWEEP`。这是当前 Java API 变化，不加旧构造器/字段兼容层，事实不授予写权限。
